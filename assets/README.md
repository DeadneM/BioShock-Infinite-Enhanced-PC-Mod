# InfiniteMod artwork

Created with the built-in ImageGen tool for this community mod; not official publisher artwork.

- `infinitemod-cover-16x9.png`: 1672x941 PNG, near16:9 cover composition. Original generated dimensions retained without resampling.
- `infinitemod-banner.png`: 2172x724 PNG, exact3:1 panoramic banner used by the README.

The title is BIOSHOCK INFINITE / ENHANCED PC MOD, with no baked-in version number. Both files use matching floating-city architecture, ivory/brass details and a navy plaque. Text and framing were visually checked after generation. The exact prompt set is in [PROMPTS.md](PROMPTS.md). Original generated files remain in the local generation archive; these copies are stored in the repository so its documentation is self-contained.
